## AikenVPN 2.5.0 для Windows 10/11 x64

- Поиск по названию, серверу и протоколу, избранные профили и настраиваемая глобальная горячая клавиша подключения. При конфликте сочетаний сохраняется прежняя настройка.
- Локальные профили шифруются через Windows DPAPI. Старое хранилище автоматически обновляется после успешного чтения. Перед показом или копированием ключей и паролей приложение запрашивает подтверждение.
- Переносимый архив профилей с паролем. Перед восстановлением видны добавляемые и заменяемые профили.
- Исправления отмены подключения и очистки маршрутов WireGuard и Windows RAS. OpenVPN очищает временные файлы и сообщает об остановке процесса. Xray при штатном отключении восстанавливает системный прокси и сохраняет обнаруженные сторонние изменения.
- Статус соединения обновляется по событиям. Фоновый TCP-тест на главном экране удалён. Ручная диагностика доступна по-прежнему.
- Исправлено распознавание секций WireGuard и редактирование импортированных профилей.

### Установка и совместимость

Скачайте EXE для Windows x64 и запустите его. Для OpenVPN нужен установленный системный OpenVPN.

При откате на AikenVPN 2.4.x прежняя версия не сможет открыть уже зашифрованный файл профилей. Для такого отката заранее сохраните совместимый экспорт и защищайте его как файл с учётными данными. Для переноса между ПК с поддержкой 2.5.0 используйте архив в разделе «Настройки → Данные».

Сборка без цифровой подписи. SHA-256 позволяет сверить скачанный файл с опубликованным. Kill switch, правила для разных сетей и подписанные автообновления остаются в плане.
